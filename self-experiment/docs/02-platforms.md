## 順番

**ココナラ → note → 自分のサイト**

1. 買い手が既にいる場所で実績を作る
2. 発信が育ったら、発信と販売が同じ場所にある note に寄せる
3. 手数料を下げたくなったら自分のサイトに移す

MENTA は月額プランの受け皿として、規約を確認してから検討する。

## ココナラで確認できたこと（2026-11-13、検索結果に出た公式ヘルプの要約による）

> help.coconala.com の本文はこの環境から直接読めず、検索エンジンが公式ページから抜き出した要約で確認した。出品前に原文を読む。

| 項目 | 内容 | 設計への反映 |
|---|---|---|
| 外部への誘導 | 外部の連絡先の交換、他サイトの登録フォームへの誘導、メッセージ・申し込み機能のあるサイトのURL共有は禁止。データのやり取りはファイル添付を使うよう案内（Googleフォームは使えないツールとして記載）（[ヘルプ](https://help.coconala.com/hc/ja/articles/10003485737881)） | 記録はお客さんごとの Excel をトークルームで受け渡す（`run sheet`）。記録フォーム（`form/`）はお客さんに使わない |
| 添付ファイル | 1ファイル100MB・1回5個まで。形式は excel / word / pdf / powerpoint / txt / 画像 / 動画 / 音声 / zip など。CSV・HTML は一覧にない | 記録は .xlsx、納品は PDF |
| AIの利用 | AIで作ったイラスト画像は出品できない。AIで作った文章・PDF資料は出品できる例に挙がっている。AI利用の明記義務は見つからなかった（[ヘルプ](https://help.coconala.com/hc/ja/articles/48479864968729)） | 出品文に「分析プログラムとAIの補助で作り、担当者が確認」と書く。図は統計のグラフだけ |
| 売上の確定 | 正式な納品の後、72時間以内に承諾か差し戻し（1回まで）。回答がなければ自動承諾。トークルームはオープンから120日で自動クローズ（[ヘルプ](https://help.coconala.com/hc/ja/articles/218723567)） | 56日の並びでも120日に収まる。売上は最終の納品の後に入る（01-service.md「売上が入る時期」） |
| 健康関連 | 医療行為、病気に効く薬や特定の症状に効能を持つ食品・サプリの紹介は出品できない（[ヘルプ](https://help.coconala.com/hc/ja/articles/9517249749017)） | 成分を勧めない・効能を言わない設計のまま。出品文の禁止語をテストで確認（`sales/`） |
| 価格 | 最低価格はカテゴリごと（最も低いカテゴリで500円）。同じ内容を複数の価格で出せず、差はオプションで付ける | 入口（出品A）と本番（出品B）は内容が違う別の出品にする |
