# 02. 出品先

| 場所 | 手数料 | 向いている点 | 未確認 |
|---|---|---|---|
| ココナラ | [22%](https://hanapapa-side-business.com/coconala-checklist/)（ビデオチャットは27.5%） | 習慣化の伴走に買い手がいる | AI生成の文章を納品物にできるか（記事によって食い違う）。売上の確定時点 |
| note メンバーシップ | [10%＋決済・振込手数料](https://note.com/lp/membership) | 月額100〜50,000円、プラン5つまで。発信と販売が同じ場所 | 集客は自分の発信次第 |
| MENTA | [利用手数料15%＋決済5%](https://menta.work/post/detail/24/Rna4LAj8yQAU1MOOjuIt) | 月額プランを作れる（最低3,000円） | 健康系の伴走が規約上どこまで可能か（カテゴリの情報が2019年時点） |
| タイムチケット | [一律10%の告知あり](https://www.timeticket.jp/)（掲載日不明） | 時間単位の相談向き | 4週間の伴走には形が合わない。健康関連の禁止事項 |
| 自分のサイト | 決済手数料のみ | 手数料が最も低い | [特定商取引法の表記が必須](https://www.no-trouble.caa.go.jp/qa/advertising.html)。住所と電話は「請求があれば遅滞なく開示する」と書けば省略できる（実際に開示できる体制が条件） |

## 順番

**ココナラ → note → 自分のサイト**

1. 買い手が既にいる場所で実績を作る
2. 発信が育ったら、発信と販売が同じ場所にある note に寄せる
3. 手数料を下げたくなったら自分のサイトに移す

MENTA は月額プランの受け皿として、規約を確認してから検討する。
