# 02. 出品先

販売先ごとの決まり（手数料・売上が入る時期・やり取りの場所・ファイルの受け渡し・外部リンクの可否・出品前に確かめること・出典）は
`engine/n1engine/channels/profiles.py` に1か所で持ち、`python -m n1engine.run sales --out ../sales` で次を作る。

- [../sales/README.md](../sales/README.md)：販売先ごとの準備（確かめること・出典）
- [../sales/pricing.md](../sales/pricing.md)：販売先ごとの手取りと、月5万円に必要な件数
- `../sales/<販売先>/`：出品文（入口・本番）と定型文。サービスの説明は `channels/content.py` の1か所から作るので、販売先ごとに食い違わない
- 自分のサイト：`python -m n1engine.run site --config site.json --out 公開用` で、紹介・特定商取引法の表示・記録の扱いのページを作る

## 使う販売先と順番（2026-11-15）

| 販売先 | 手数料 | 合う点 | 合わない・未確認の点 |
|---|---|---|---|
| ココナラ | 22% | 習慣化の伴走に買い手がいる。トークルームで Excel・PDF を受け渡せる | 外部への誘導が禁止。健康関連の扱いは運営に要確認 |
| note | 約15% | 発信と販売が同じ場所。メンバーシップに1対1プランがある | 個別のメッセージ機能がなく、受け渡しはメール（認められるか要確認） |
| MENTA | 20%（買い手にも10%） | 月額で2か月の伴走にできる | 添付できる形式に Excel が無い（古い記事）。提供期間は1か月が上限 |
| タイムチケット | 25%（5万円以下） | Excel・PDF を添付できる | 手数料が高い。外部リンクの掲載は禁止 |
| 自分のサイト（Stripe） | 3.6% | 手数料が最も低い。文面の制約が少ない | 特定商取引法の表示・最終確認画面・記録の扱いの公開を自分で用意。Stripe の審査で健康関連と見なされないか要確認 |

使わない：BASE（無形の商品でも追跡できる有形物の発送が必須）、STORES（役務の商品の種類がない）、ストアカ（リアルタイムの講座が必須）、Peatix（イベントのチケット販売）。理由と出典は sales/pricing.md。

**順番**：ココナラで最初の実績を作る → 同じ時期に note で自分の実験を発信し、note からも売る → 実績と表示の準備がそろったら自分のサイトに寄せて手数料を下げる。MENTA とタイムチケットは、Excel の受け渡しと手数料を確かめてから。

## ココナラで確認できたこと（2026-11-13、検索結果に出た公式ヘルプの要約による）

> help.coconala.com の本文はこの環境から直接読めず、検索エンジンが公式ページから抜き出した要約で確認した。出品前に原文を読む。

| 項目 | 内容 | 設計への反映 |
|---|---|---|
| 外部への誘導 | 外部の連絡先の交換、他サイトの登録フォームへの誘導、メッセージ・申し込み機能のあるサイトのURL共有は禁止。データのやり取りはファイル添付を使うよう案内（Googleフォームは使えないツールとして記載）（[ヘルプ](https://help.coconala.com/hc/ja/articles/10003485737881)） | 記録はお客さんごとの Excel をトークルームで受け渡す（`run sheet`）。記録フォーム（`form/`）はお客さんに使わない |
| 添付ファイル | 1ファイル100MB・1回5個まで。形式は excel / word / pdf / powerpoint / txt / 画像 / 動画 / 音声 / zip など。CSV・HTML は一覧にない | 記録は .xlsx、納品は PDF |
| AIの利用 | AIで作ったイラスト画像は出品できない。AIで作った文章・PDF資料は出品できる例に挙がっている。AI利用の明記義務は見つからなかった（[ヘルプ](https://help.coconala.com/hc/ja/articles/48479864968729)） | 出品文に「分析プログラムとAIの補助で作り、担当者が確認」と書く。図は統計のグラフだけ |
| 売上の確定 | 正式な納品の後、72時間以内に承諾か差し戻し（1回まで）。回答がなければ自動承諾。トークルームはオープンから120日で自動クローズ（[ヘルプ](https://help.coconala.com/hc/ja/articles/218723567)） | 56日の並びでも120日に収まる。売上は最終の納品の後に入る（01-service.md「売上が入る時期」） |
| 健康関連 | 医療行為、病気に効く薬や特定の症状に効能を持つ食品・サプリの紹介は出品できない（[ヘルプ](https://help.coconala.com/hc/ja/articles/9517249749017)） | 成分を勧めない・効能を言わない設計のまま。出品文の禁止語をテストで確認（`sales/`） |
| 価格 | 最低価格はカテゴリごと（最も低いカテゴリで500円）。同じ内容を複数の価格で出せず、差はオプションで付ける | 入口（出品A）と本番（出品B）は内容が違う別の出品にする |
