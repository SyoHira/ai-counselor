# 01. サービス設計

## 流れ

ココナラでは外部のフォーム・Webページへの誘導と外部の連絡先の交換が禁止されていて、データはトークルームのファイル添付でやり取りする（[04-compliance.md](04-compliance.md)）。そのため、記録は**お客さんごとの Excel** で受け渡す。

```
① 購入 → 定型文1（同意・購入前の確認・決めること）  ……… sales/messages.md
      ↓
② 記録用 Excel を作って送る（定型文2）
   python -m n1engine.run sheet --out 〇〇.xlsx --item ... --substance ... --outcome ... --start ...
   7日ずつの入れ替えに向かない成分（ビタミンD、オメガ3など）はここで止まる → 断ってキャンセル
   月経周期を記録する人・2つのサプリを比べる人は56日の並び
      ↓
③ 普段どおりの記録 7日 → 揺れ方と必要日数のレポート（出品A の納品物／出品B の途中経過）
   python -m n1engine.run baseline 〇〇.xlsx --pdf 揺れ方.pdf --comment @コメント.txt
      ↓
④ 実験 28日（または56日）。毎週日曜にファイルを受け取り、書き方だけ確認（定型文3。途中の判定は出さない）
      ↓
⑤ 判定とレポート（PDF、図つき）
   python -m n1engine.run analyze 〇〇.xlsx --pdf レポート.pdf --comment @コメント.txt
   成分・主要項目・並びは Excel の中の設定から読むので、打ち直さない
      ↓
⑥ 担当者がコメントを書いて納品（定型文6）→ 承諾 → 90日後に削除（定型文7）
```

電話相談・ビデオ通話はしない。やり取りはテキストのみ（ココナラではビデオチャットにすると手数料が22%から27.5%に上がる）。
自分用の記録フォーム（`form/`）は claude.ai のアーティファクトで、ココナラのお客さんには使わない（外部のWebページへの誘導になるため）。

## 対象外の条件

| 条件 | 理由 |
|---|---|
| 服薬中・通院中 | 飲み合わせ、治療への影響 |
| 妊娠中・授乳中 | 安全性 |
| 未成年 | 安全性 |
| 専ら医薬品リストの成分を含むもの | 日本では医薬品扱い。健康食品に使えない |
| 指定成分4つ（コレウス・フォルスコリー、ドオウレン、プエラリア・ミリフィカ、ブラックコホシュ） | 健康被害の報告義務がある成分 |

専ら医薬品リストは随時改定されるので、申込のたびに最新版で確認する（[厚生労働省](https://www.mhlw.go.jp/file/06-Seisakujouhou-11130500-Shokuhinanzenbu/0000086062_1.pdf)）。

## 毎日の記録

| 種類 | 項目 | 役割 |
|---|---|---|
| 主要項目 | 申込時に決めた1つ | 判定の対象。途中で変えない |
| 睡眠日誌（翌朝） | 寝つくまでの時間、途中で起きていた時間、眠っていた時間、睡眠の質 | 参考項目 |
| 装着型機器（ある人） | 睡眠中の心拍数、心拍変動 | 参考項目 |
| 自己評価（寝る前） | 気分、ストレス | 参考項目 |
| 生活記録 | 飲酒、カフェイン飲料、休日、体調不良、月経周期の日、実際に飲んだ時刻 | 外部要因（補正）・体内量の計算 |

参考項目は補正に使わない（飲んだことで動きうるため）。判定の言葉は主要項目にだけ付ける。

### 売上が入る時期

ココナラの売上は、正式な納品のあと、承諾（または72時間後の自動承諾）で確定する（[04-compliance.md](04-compliance.md)）。本番の実験は購入から納品まで 7日＋28日＋5日 ≒ 40日（56日の並びなら約68日）かかる。

- 「2ヶ月で月5万円」を2ヶ月目に入れるには、28日の実験を**最初の約3週間で**売る必要がある。56日の並びは2ヶ月以内に入らない
- 入口（出品A）は購入から約10日で確定する。最初の数週間の売上と評価は入口で作り、本番に進んでもらう

## 確認できていないこと

- 最初の1件までの期間（[1ヶ月かかった体験談](https://coconala-guide.com/coconala-start-guide/)は1件のみ）
- 4週間のサービスで売上が確定する時点。取引完了まで確定しないなら、2ヶ月目に買った人の売上は3ヶ月目に入る
