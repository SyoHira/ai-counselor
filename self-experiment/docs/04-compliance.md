# 04. 規制と、出品前に確認すること

> 事業判断の整理であり、法的助言ではない。

## 確認できたこと

| 項目 | 内容 |
|---|---|
| 効能の表現 | サプリに医薬品的な効能効果を表示すると薬機法違反。[個人のアフィリエイターも対象](https://health-beauty-soleil.jp/supplement-advertising/)。[体験談や画像で暗示するのも違反になりうる](https://www.yakujihou.com/knowledge/supplement-advertisement/) |
| 体験談 | 消費者庁は体験談で効果を暗示する表示を規制対象の類型に挙げ、[注記をつけても判断は変わらない](https://www.caa.go.jp/policies/policy/representation/extravagant_advertisement/assets/representation_cms214_221205_02.pdf)としている |
| 食品に使えない成分 | [専ら医薬品リスト](https://www.mhlw.go.jp/file/06-Seisakujouhou-11130500-Shokuhinanzenbu/0000086062_1.pdf)の成分を1つでも含めば医薬品扱い。リストは随時改定 |
| 指定成分 | [4成分](https://www.kenko-media.com/health_idst/archives/15356)に健康被害の報告義務 |
| 不当表示 | 消費者庁は根拠資料の提出を求めることができ、[出せなければ不当表示とみなされる](https://www.caa.go.jp/policies/policy/representation/fair_labeling/representation_regulation/misleading_representation)。[故意・過失がなくても措置命令の対象](https://www.caa.go.jp/policies/policy/representation/fair_labeling/pdf/fair_labeling_160801_0001.pdf) |
| ステマ規制 | 自分のサービスの宣伝は宣伝と分かる形で。[第三者を装う投稿や自作自演は規制対象](https://www.nttcoms.com/service/social/column/stealth_marketing/) |
| ココナラの規約 | [効果の断定・誇張は禁止行為、資格を示さずに提供することも違反例](https://coconala.com/news/1118) |
| 公的データベース | 国立健康・栄養研究所の[素材情報データベース](https://hfnet.nibn.go.jp/material-infodb/)は、無断転用・引用・商用利用が原則禁止。レポートや成分の説明に文章を転用しない |

## このサービスの設計で避けていること

- 成分や商品を勧めない（「個別提案が適法か」という未確認の論点を避ける）
- 「効果」「効く」「効力」を使わない（エンジンのテストで毎回確認）
- 病名を扱わない。気分は0〜10の簡単な評価にとどめ、うつ病の尺度などは使わない
- レポートは本人にだけ渡し、公開しない
- 「量子」は研究していることだけを書く

## 出品前に確認すること

| # | 確認すること | 確認先 |
|---|---|---|
| 1 | 「勧めず、本人が選んだものを確かめるだけ」の形が問題ないか | 薬機法・景表法に詳しい専門家 |
| 2 | 自分の実験を「方法とデータ」として出す形が、体験談の規制に触れないか | 同上 |
| 3 | AI生成の文章を納品物にできるか（[出品可能とする記事](https://coconala.com/blogs/6165551/784593)と原則不可とする記事で食い違う） | ココナラ公式ヘルプ「AI技術を使用した出品に対するスタンス」 |
| 4 | 4週間のサービスで売上が確定する時点 | ココナラ公式ヘルプ |
| 5 | 健康系の伴走が規約上どこまで可能か | MENTA・タイムチケットの利用規約（使う場合） |
| 6 | 体調の記録を預かるときの個人情報の扱い（同意の取り方、保存場所、削除） | 個人情報保護委員会の資料、専門家 |
