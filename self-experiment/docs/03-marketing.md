# 03. SNS

## どこにいるか

| 場所 | 確認できたこと |
|---|---|
| note | サプリの体験記が大量にある（[アシュワガンダ](https://note.com/zumi_ke/n/nf6c9f82e6eee)、[ロディオラ](https://note.com/lu319150/n/n00e308fabdea)、[コーヒーを1ヶ月やめてみた](https://note.com/brainy_ixia849/n/ne605821a1eb3)など）。ここが顧客層 |
| Instagram | 日本語のバイオハック系の発信者はいる。検証方法を扱うアカウントは見つからなかった |
| X | 専門家が [N-of-1試験に言及](https://x.com/syuichiao89/status/2074791071998181783) している。検索エンジンに投稿がほぼ載らないため、網羅は確認できていない |

フォロワーゼロから何が集客に効くかの数字は見つからなかった。出してみて測る。

## 何を出すか

**自分の実験を、方法とデータとして出す。**

- 何を何日、どう記録し、どう判定したか
- 差が出たか、出なかったか。**差が出なかった実験も同じ形で出す**
- エンジンの検証結果（「普通の比較は、差がなくても最大16.5%の確率で『差がある』と言う」など、自社で確かめた数字）

## 守ること

| 決まり | 理由 |
|---|---|
| 「このサプリは効く」と書かない。「私の記録ではこういう差が出た。方法はこう」と書く | [体験談で効果を暗示することは規制対象の類型](https://www.caa.go.jp/policies/policy/representation/extravagant_advertisement/assets/representation_cms214_221205_02.pdf)で、注記をつけても判断は変わらない |
| 宣伝は宣伝と分かる形で出す。第三者を装わない、自作自演をしない | [ステマ規制](https://www.nttcoms.com/service/social/column/stealth_marketing/)（2023年10月施行） |
| 特典と引き換えにお客さんに感想を投稿してもらう場合は、その関係を明示する | 同上 |
| 商品名・購入リンク・アフィリエイトを出さない | 勧めないサービスの立場を守る |

## 量子の出し方

研究していることは事実なので書ける。根拠のないまま「優れている」と見せるのが不当表示にあたる（[消費者庁は根拠資料の提出を求めることができ、出せなければ不当表示とみなされる](https://www.caa.go.jp/policies/policy/representation/fair_labeling/representation_regulation/misleading_representation)）。

| 書ける | 書けない（自社データで確かめるまで） |
|---|---|
| 「量子認知の研究を、自社の記録データで検証しています」 | 「量子分析で精度が上がる」 |
| 「質問の順番による回答の偏りを、量子確率モデルで研究しています」 | 「量子で差が分かる」 |
| 研究の途中経過（成り立った／成り立たなかった）の公開 | 量子で出した結果を顧客のレポートに入れる |

基本の打ち出しはデータサイエンス・医療統計（前日の引きずりを考慮したベイズ判定、自社で行った検証）。量子は研究としての補足に置く。
