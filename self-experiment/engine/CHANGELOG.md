# 変更記録

分析方法を変えるときは、何を・なぜ・根拠を書き、版番号を上げ、`scripts/calibrate.py` を再実行して CALIBRATION.md を更新する。
レポートには使った版が載るので、過去のレポートがどの方法で出たかを後から追える。

## v0.3.0（2026-10-17）

**追加**
- `domain/pd.py`：記録に現れるまでの遅れ（薬力学の持ち越し）。作用部位モデル（Sheiner 1979）・間接反応モデル（Dayneka 1993）が影響の比例する範囲で共通に持つ「一次の遅れ」を、1日ごとの式で体内量にかける。遅れの半減期（0〜7日の候補7つ）をギブスサンプリングの1段で推定する。事前の重みは「遅れなし」0.75（0.5／0.75／0.9／1.0 を偽データで比べて決めた）
- t 分布の揺れ（Geweke 1993 の正規分布の混合）：外れた日の重みを自動で下げ、レポートにその日を出す。自由度は 3〜100 の候補から推定
- `research/quantum.py`：質問の順番の量子確率モデル（2次元の実ベクトル空間、Lüders 射影）。古典・量子2次元・QQ・自由の4モデルを BIC で比べ、QQ等式を尤度比で検定する。`run quantum`
- `research/population.py`：複数人の1人実験をまとめる階層ベイズ（Zucker 1997）。`run pool`
- 記録フォームに「はい／いいえ」2問（順番をランダムに入れ替え、その日の最初に聞く）。書き出しに qa・qb・pair_order
- `run analyze --no-pd`：遅れが無いと分かっている場合に、遅れの推定を切る

**変更**
- 「90%の幅」：遅れの推定と t 分布で幅が広がり、名目95%の幅が実際95〜98%を含むようになったため、名目90%の幅に戻した（再検証で88.5〜93%）
- 必要日数の見積もり（`run plan`）を、判定と同じ設定（遅れ・t 分布）で計算するようにした

**検出力との引き換え**
- 基本の検証で、差ゼロの誤りは 5.5〜7.5% → 3.5〜4.0%、差1点を見つけた割合は 46.0% → 38.0%（引きずり0.5）、37.5% → 29.5%（0.8）。遅れがあり得ることを計算に入れた分、慎重になった
- 遅れ2日の偽データでは、推定 0.62 → 0.78、90%の幅の正しさ 80% → 95%

## v0.2.0（2026-10-16）

専門領域（薬物動態学・睡眠・自律神経・内分泌・時間生物学）の変数を入れ、v0.1.0 の要素別の検証で見つかった5つの問題を直した。

**追加**
- `domain/pk.py`：1コンパートメントの経口モデル（Bateman式、重ね合わせ）で、記録の時間帯（その夜／日中）に体に残っている量（曝露量、定常状態=1.0）を毎日計算し、0/1 の代わりに使う。記録の時間帯に残る量、7日ずつの入れ替えへの向き、実験前に空ける日数（半減期の5倍）を出す
- `domain/substances.py`：出典を確認できた数値だけの成分一覧（カフェイン、L-テアニン、ビタミンD、オメガ3、マグネシウム）。半減期を確認できないものは推測で埋めない
- `domain/variables.py`：記録項目の一覧。領域・単位・時間帯・役割（体の反応／外部要因／周期／体内量を変えるもの）・変換（RMSSD は対数）
- 月経周期を記録する人向けの56日の並び（ABABBABA／BABAABAB）。28日の ABBA は周期の長さ25〜35日のどれでも、どこから始めても周期の時期との重なりが約0.9になるため
- 主要項目と参考項目の区別。判定の言葉は主要項目にだけ付ける（CONSORT 2010 項目6a、CENT 2015）
- 分・拍/分・対数の項目を扱う（飲まない期間のばらつきでそろえて同じ事前の前提を使い、元の単位に戻して出す）
- `diagnostics.py`：4本並行の計算と、順位で正規化した分割 R̂・有効な推定回数（Vehtari 他 2021）。レポートに載せる
- `run substances`、`pipeline.py`

**直した問題（CALIBRATION.md の v0.1.0 要素別の検証）**
1. 補正しすぎ：気分・ストレス・睡眠を補正から外した。外部要因（飲酒・休日・体調不良・月経周期）だけを補正する。気分を通じた差がある偽データで、推定 0.51 → 0.91（本当は1.0）
2. 偶然との比較：補正前の単純な差ではなく、時間の流れと外部要因を差し引いた後の差で比べる。悪い方向の差も、その向きで比べる。差ゼロで「20回に1回以下」が出た割合 6.0%
3. 持ち越し：曝露量で扱う。半減期2日の偽データで、推定 0.51 → 0.81（本当は1.0）、幅の正しさ 83% → 93%
4. 収束診断：4本並行、R̂ と有効な推定回数を出す
5. 必要日数の候補：10日ブロックをやめ、7日の倍数（28日・56日）だけにする

**その他**
- 外部要因の空欄で、その日を丸ごと捨てていたのを、平均で埋めるように変えた（空欄の日数はレポートに出す）
- 見本の記録を、カフェイン15時・寝つくまでの時間・56日に作り直した

## v0.1.0（2026-10-13）

- 最初の版
- 前日の引きずりを含めたベイズ回帰（Chib 1993 のギブスサンプリング）
- 時間の流れ、気分・ストレス・睡眠を同時に考慮
- 幅：検証で名目90%が実際85%だったため、内部で95%の幅を計算して「90%の幅」として出す
- 必要日数の見積もり：普段の記録から揺れ方の候補を何千通り出し、その不確かさごと計算する（1つの値に決め打ちすると楽観的になるため）。普段の記録は7日以上を必須にする
- 研究層：QQ等式の検証（顧客のレポートには使わない）
