# 1人実験の結果：カフェイン（15時）

主要項目：寝つくまでの時間（その夜（23時〜翌7時））　／　記録日数：53日　／　分析エンジン v0.3.0

## 結論

**悪い方向にはっきり差がある**

あなたの記録では、飲んだ期間の方が「寝つくまでの時間」が良かった確率は **1%** でした。

記録の上では、飲んだ期間の方がはっきり良くない結果でした。続けるかどうか見直す材料になります。

## 数字で見る

- 差の大きさ：平均 **+6分（90%の幅：+2〜+9分）**
  - 飲み続けて体内の量が安定したときの差です。飲み始めの数日と、やめた後に体に残っている数日は、残っている量に応じて計算に入れています。
- 前日の体調の引きずり：0.51（0なら毎日が独立、1に近いほど前日を強く引きずる）

「90%の幅」は、本当の差がこの範囲に入っている見込みが90%という意味です。幅が0をまたいでいる場合は、差がない可能性も残っています。

## 偶然と比べると

時間の流れと外部要因を差し引いた後の差（悪い方向）は、あなたの普段の揺れ方で差がゼロの記録を何千回も作ってみると、**約2000回に1回**は偶然でも出ます。

## 成分の体内での動き

- 成分：カフェイン
- 体内で半分になるまでの時間（半減期）：5時間（個人差 1.5〜9.5時間）
- 飲んでから最も濃くなるまで：約1時間
- 飲む時刻 15時のとき、その夜（23時〜翌7時）に体に残っている量：1日の最高時の約24%
- 実験の前に空ける日数の目安：2日（半減期の5倍）
- 95%以上が肝臓の酵素 CYP1A2 で分解され、半減期の個人差が大きい。就寝6時間前の400mgでも睡眠が乱れたという報告がある（12人の研究）。
- 7日ずつ入れ替える実験への向き：**向いている**。飲む期間と飲まない期間の体内量の差は、0/1で切り替わる場合の99%。
- 数値の出典（2026-10-16確認）：
  - [半減期 平均約5時間・幅1.5〜9.5時間、CYP1A2（ISSN 2024）](https://www.tandfonline.com/doi/full/10.1080/15502783.2024.2323919)
  - [最高濃度まで 約30分（5mg/kg、10人）](https://link.springer.com/doi/10.1007/BF00613933)
  - [最高濃度まで コーヒー約1.0時間・カプセル約1.6時間](https://pmc.ncbi.nlm.nih.gov/articles/PMC9202019/table/tbl1)
  - [就寝0・3・6時間前の摂取と睡眠（Drake 2013）](https://www.semanticscholar.org/paper/Caffeine-effects-on-sleep-taken-0,-3,-or-6-hours-to-Drake-Roehrs/d5fac59f050a5a07efc47f58abcdbaf1d880c0c3)

## 記録に現れるまでの遅れ

体に入った量は、すぐに記録に現れるとは限りません。働く場所に届き、体の反応が入れ替わるまでの遅れがあると、飲むのをやめた後も数日は記録に影響が残ります。この遅れの長さも、あなたの記録から推定しました。

| 遅れ（半分になるまでの日数） | 見込み |
|---|---|
| 遅れなし | 90% |
| 0.5日 | 4% |
| 1日 | 2% |
| 2日 | 2% |
| 3日 | 1% |
| 5日 | 1% |
| 7日 | 0% |

遅れはほとんど無いと見られます。

前提：影響の大きさが体の中の量に比例する範囲で考えています（薬力学の作用部位モデル・間接反応モデルの考え方）。

## そろえて比べたもの

飲んだかどうか以外で記録を動かしうる外部要因は、分析の中で差し引いています。

- 時間の流れ（季節や生活の変化）
- 飲酒（杯）（空欄2日は平均で埋めた）
- 休日
- 月経周期の時期
- 前日の体調の引きずり
- ふだんの揺れより大きく外れた日は見当たりませんでした（外れた日があれば重みを下げる計算にしています）

気分・ストレス・睡眠・心拍などの体の記録は、飲んだことで動きうるため差し引いていません。差し引くと、それを通じて生じた差まで消してしまいます。

## この分析で言えないこと

- 中身を知った上で飲んでいるため、「飲んだから」なのか「飲んだと分かっていたから」なのかは区別できません。区別するには、中身を隠す上級版が必要です。
- この結果はあなたの記録についてのものです。他の人に当てはまるかどうか、成分そのものの働きについては何も言えません。
- 体調が変わった理由を特定するものではありません。気になる症状がある場合は医療機関に相談してください。

## 方法

- 設計：飲む期間と飲まない期間を折り返す順番で4期間（推定に使えた連続した日のペア：49組）
- 分析：前日の引きずりを含めたベイズ回帰。飲んだかどうかは、成分の体内動態から計算した「記録の時間帯に体に残っている量」で表す（1コンパートメントの経口モデル）
- 記録に現れるまでの遅れ（一次の遅れ、候補7つ）と、外れた日に強い揺れ（t 分布）を同時に推定
- 事前の前提：差は0を中心に±2点程度（0〜10以外の項目は、飲まない期間のばらつきを1点としてそろえる）。実験前に固定
- 判定基準：良かった確率95%以上で「はっきり差がある」、80%以上で「差がありそう」。主要項目は実験前に1つ決める
- 分析エンジン v0.3.0。答えの分かっている偽データで、判定の誤りの割合と幅の正しさを検証済み（CALIBRATION.md）
