# 1人実験の結果：マグネシウム（就寝前）

主要項目：朝のだるさの少なさ（日中（9時〜21時））　／　記録日数：28日　／　分析エンジン v0.5.0

## 結論

同じ成分・同じ項目で試した方 11人の記録の傾向を土台にして、**あなたの記録**から推定した結果です。結果はあなた1人についてのものです。

**差がありそう**

あなたの場合、飲んだ期間の方が「朝のだるさの少なさ」が良かった確率は **95%** でした。

記録の上では、飲んだ期間の方が良かった可能性があります。ただし、はっきりと言える水準には届いていません。

## 数字で見る

- 差の大きさ：平均 **+0.9点（90%の幅：-0.0〜+2.0点）**
  - あなたの記録だけで推定した場合：+2.1点（90%の幅：-0.0〜+4.0点）（良かった確率 95%）
  - 他の方の傾向を土台にすると、短い記録でも揺れに振り回されにくくなります。土台の重みは、あなたの記録が確かなほど小さくなります。
- 1点以上良かった確率：41%
- 前日の体調の引きずり：0.55（0なら毎日が独立、1に近いほど前日を強く引きずる）

「90%の幅」は、本当の差がこの範囲に入っている見込みが90%という意味です。幅が0をまたいでいる場合は、差がない可能性も残っています。

## 期待の分

中身を隠して試した方 4人と、中身を知って試した方の記録を比べ、中身を知っていることで記録が動く分（期待の分）を推定しました：平均 +0.02（95%の幅 -1.02〜+1.02）。上の差は、この分を差し引いたあなたの差です。

## 記録に現れるまでの遅れ

体に入った量は、すぐに記録に現れるとは限りません。働く場所に届き、体の反応が入れ替わるまでの遅れがあると、飲むのをやめた後も数日は記録に影響が残ります。この遅れの長さも、あなたの記録から推定しました。

| 遅れ（半分になるまでの日数） | 見込み |
|---|---|
| 遅れなし | 5% |
| 0.5日 | 1% |
| 1日 | 2% |
| 2日 | 13% |
| 3日 | 78% |
| 5日 | 0% |
| 7日 | 0% |

遅れがある見込みが95%です。次に試すときは、飲まない期間の最初の数日を長めに取ると比べやすくなります。

あなたの実験の並びでは、5日・7日の遅れは、体調のゆるい変化と見分けられないため候補から外しました（3日までを見ています）。もっと長い遅れを確かめるには、14日ずつの並びで試します。

遅れの見込みには、同じ成分・同じ項目で試した方 11人の結果を事前の重みとして使っています。

## そろえて比べたもの

飲んだかどうか以外で記録を動かしうる外部要因は、分析の中で差し引いています。

- 時間の流れ（季節や生活の変化）
- 前日の体調の引きずり
- ふだんの揺れより大きく外れた日は見当たりませんでした（外れた日があれば重みを下げる計算にしています）

気分・ストレス・睡眠・心拍などの体の記録は、飲んだことで動きうるため差し引いていません。差し引くと、それを通じて生じた差まで消してしまいます。

## 方法

- 設計：飲む期間と飲まない期間を折り返す順番で4期間（推定に使えた連続した日のペア：27組）
- 分析：前日の引きずりを含めたベイズ回帰。飲んだかどうかは、成分の体内動態から計算した「記録の時間帯に体に残っている量」で表す（1コンパートメントの経口モデル）
- 記録に現れるまでの遅れ（一次の遅れ、候補7つ）と、外れた日に強い揺れ（t 分布）を同時に推定
- 事前の前提：差は0を中心に±2点程度（0〜10以外の項目は、飲まない期間のばらつきを1点としてそろえる）。実験前に固定
- 判定基準：良かった確率95%以上で「はっきり差がある」、80%以上で「差がありそう」。主要項目は実験前に1つ決める
- 分析エンジン v0.5.0。答えの分かっている偽データで、判定の誤りの割合と幅の正しさを検証済み（CALIBRATION.md）
