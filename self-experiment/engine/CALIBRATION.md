# 検証記録

分析方法を変えたら、`python scripts/calibrate.py` を再実行してここに記録する。
宣言している数字（「90%の幅」「95%以上ではっきり差がある」）と、実際の振る舞いが合っていることが、このエンジンの信用の土台になる。

## v0.4.0（2026-10-17）

複数人の記録を前提に分析し、レポートにはその人の結果だけを出す形にした。v0.3.0 で「言えないこと」としていた項目を、1つずつ手当てした。

### 実際の記録での確認（`python scripts/realdata.py`）

公開されている実際の1人実験（nof1kit 同梱、メラトニン70日、1〜2日で入れ替わる並び、気分を1日3回）。

```

前の夜に飲んだか｜遅れあり：悪い方向に差がありそう 差 -0.12（90%の幅 -0.30〜+0.06） 良かった確率 14%｜当てはまり：予測幅に入った日 93%（69日） 規則性 p=0.40 期間のずれ p=0.34 → 合っている｜外した遅れ [1.0, 2.0, 3.0, 5.0, 7.0]
前の夜に飲んだか｜遅れなし：悪い方向に差がありそう 差 -0.12（90%の幅 -0.29〜+0.06） 良かった確率 14%｜当てはまり：予測幅に入った日 93%（69日） 規則性 p=0.42 期間のずれ p=0.33 → 合っている
```

- 最初の版（遅れの候補をすべて残す）では、遅れを入れると差が +0.07 → +0.50 に膨らみ、判定が「差がありそう」に変わった。長い遅れの体内量は実験の初めからゆっくり上がる形になり、体調のゆるい変化と見分けがつかないため。並びごとに見分けられる遅れだけを残す処理（`pd.identifiable`）を入れて、+0.07 に戻った。
- 当てはまりの確認は、どの分析でも「合っている」（予測幅に入った日 93%、目安90%）。

### 分かったこと

1. 複数人を前提にすると、1人の推定の誤差は半分以下になり、遅れの見分けも 22% → 63% に上がった。ただし、遅れの重みは「各人の見込みの足し合わせ」ではなく「各人の当てはまりの掛け合わせ（EM）」で作らないと、幅が正しくならなかった。
2. 期待の分は、中身を隠した人が4人いれば、中身を知った人の偏りをほぼ取り除けた（0.41 → 0.06）。中身を隠した人がいないうちは推定できないので、上級版の人を一定数集める。
3. 実際の記録で、偽データでは出なかった問題（長い遅れと体調のゆるい変化の取り違え）が見つかった。並びごとに見分けられる遅れだけを残して直した。
4. 当てはまりの確認は、56日なら想定外の引きずり（2日前）を74%見つけるが、28日では14%。水準の段差は見つけにくいが、差の推定は大きく崩れず、幅が広がる。
5. 量子の階層モデルは、1人分では見分けられなかったモデルを、5人で90%、20人で98%見分けた。各人の結果は10人以上で出す。

### 分かったこと

1. **持ち越しは、曝露量で数えると推定の偏りが小さくなるが、見つけやすさは上がらない。** 0/1 では本当の差の約半分（0.51）にしか見えず、90%の幅が正解を含むのは83%だった。曝露量では0.81、93%。ただし「はっきり差がある」と言えた割合は19%で、0/1（22%）と変わらない。持ち越しのある成分は、飲む期間と飲まない期間の体内量の差そのものが小さい（半減期2日で67%）ため。`run substances` と `run plan` で実験前に分かるようにした。
2. **半減期を誤っても大きくは崩れない。** 半分に誤ると0.72、倍に誤ると0.86。差ゼロのときの誤りは4〜5%のまま。半減期の個人差（カフェインで1.5〜9.5時間）があっても、致命的にはならない。
3. **月経周期は、28日の実験では避けられない問題になる。** 周期で記録が動く人を28日・補正なしで分析すると、差ゼロでも13%で「はっきり差がある」と言う（目標の5%の2倍以上）。補正すると誤りは4%に戻るが、周期と飲んだ期間の並びがほぼ重なる（重なり0.9）ため、差1点を見つけられるのが25%に落ちる。56日の並びでは誤り5%・検出80%。
4. **補正しすぎは直った。** 気分を補正から外したことで、気分を通じた差が残る（0.91）。
5. **単位のある項目も、偏りは小さく幅は正しい。** 推定は本当の値の8〜19%ほど0に寄る（控えめな事前の前提の影響）。幅の正しさは93〜95%。

### まだ測っていないこと

- 実際の人の記録での振る舞い（すべて偽データでの検証）
- 薬力学の持ち越し（体内量が消えた後も影響が残る場合）
- 月経周期の影響の形が sin・cos の波で表せない場合
- 装着型機器の測定誤差そのもの（機器ごとの精度の差）

### 分かったこと

1. **普通の比較は、差がなくても10〜16.5%の確率で「差がある」と言う。** 前日の引きずりが強いほど悪化する。
   このエンジンは目標の5%前後に収まった。
2. **最初の版では「90%の幅」が実際には85%しか正解を含まなかった。** 短い記録では引きずりの強さを小さめに見積もる傾向があり（統計学で知られた性質。60回の試行で正解0.5に対し平均0.41）、その分だけ幅が狭くなっていた。
   内部で95%の幅を計算し、それを「90%の幅」として出すように修正し、91〜92%になることを確認した。
3. **28日では足りないことが多い。** 本当に1点の差があっても、「はっきり差がある」と判定できたのは、前日の引きずり0.5で47%、0.8で38.5%。
   普通の比較の方が高い（67.5%、51%）のは、差がないときにも「ある」と言う性質の裏返し。
   → 実験前のシミュレーション（`run plan`）で、その人に必要な日数を出す。
4. 気分・ストレス・睡眠を補正に入れても推定は偏らなかった（60回の平均：差1.10／正解1.2、気分1点あたりの影響0.28／正解0.30）。

5. **必要日数の見積もりが楽観的になる問題を見つけて直した。** 穏やかな7日分の記録から揺れ方を1つの値に決め打ちしたところ、引きずり0.17・揺れ0.65と小さく推定され（本当は0.5・0.9以上）、28日で92%見つけられると出た。
   揺れ方の候補をベイズ推定で何千通り出し、シミュレーションのたびに候補から選ぶ方式に変えたところ、62%（7日分）、50%（14日分）になり、本当の値（47%）に近づいた。
   記録が少ないほど幅広い候補が残り、見積もりが慎重になる。

### まだ測っていないこと

- 必要日数の見積もりと、本当に必要な日数との一致度（多数の偽データでの系統的な比較）

- 記録の抜けが多い場合（4日以上）の振る舞い
- 0〜10の端に記録が張りつく場合（毎日10点など）の振る舞い

### 見つかった問題（v0.2.0 で直す）

1. **補正しすぎ。** 気分・ストレス・睡眠は飲んだことの影響を受けうるので、補正に入れると、それを通った差が消える。補正してよいのは、飲んだことに左右されない外部要因（天気、曜日、仕事の忙しさ）だけ。
2. **偶然との比較が補正なしの差を基準にしている。** レポートは補正後の差の話のように読める。見本では、補正なし +1.70 点、補正後 +0.70 点。
3. **持ち越し（効き始め・消え方）がモデルに無い。** 数日かかる効き方では、差を約3分の1に小さく見積もる。
4. **収束診断が無い。** 検証は1000回、本番は3000回で、収束の確認もしていない。
5. **必要日数の候補に10日ブロック（40日）がある。** 曜日が均等にならない。7日の倍数にする。

### 補足

- 「差がありそう」（80%以上）は、差ゼロでも約2割に出る。見分ける力は95%以上の方が高い（差ゼロ7%に対し差1点42%）。
- 見本の記録では、引きずりを0.85と推定した（本当は0.5）。時間・気分の差し引きは推定をほとんど動かさず（1.70→1.72）、引きずりの考慮が1.72→0.81と大きく動かした。1件の観察で、一般にそうなるかは測っていない。
