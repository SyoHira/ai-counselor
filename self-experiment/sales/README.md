# 販売先ごとの準備

`python -m n1engine.run sales --out ../sales` で作った一覧。直すときは engine/n1engine/channels/profiles.py を直して作り直す。
「要約」は検索エンジンが公式ページから抜き出した要約で確かめた値（原文は未読）。出品前に原文を読む。

販売先ごとの文面は `<販売先>/listing-entry.md`（入口）・`listing-main.md`（本番）・`messages.md`（定型文）。手取りの比較は [pricing.md](pricing.md)。

## ココナラ

- やり取りの場所：トークルーム
- ファイルの受け渡し：トークルームのファイル添付（1ファイル100MB・1回5個。Excel・PDF は可、CSV・HTML は一覧にない）
- 出品文・メッセージの外部URL：書かない（禁止）／外部の連絡先：書かない（禁止）
- 売上が入る時期：正式な納品の後、承諾または72時間後の自動承諾で確定

出品前に確かめること

- [ ] 出品前：ヘルプの原文で、AIで作った文章を納品できるか・売上の確定時点を確かめる（docs/04-compliance.md の 3・4）
- [ ] 出品前：運営に、健康関連の禁止出品に当たらないか・Excel の受け渡しが外部誘導に当たらないかを問い合わせる（同 7・8）
- [ ] 出品画面で、カテゴリの最低価格・タイトルの文字数の上限（25字は利用者ブログの値で公式は未確認）・サムネイルの寸法を確かめる。サービス画像は10枚まで（公式お知らせの要約）。画像にQRコード・メールアドレス・外部URLを入れない
- [ ] 同じ内容を複数の価格で出せないため、入口と本番は別の出品にする

## note

- やり取りの場所：メール
- ファイルの受け渡し：有料部分へのファイル添付（アプリ版は50MBまで。形式の制限は不明）。お客さんからの受け取りはメール
- 出品文・メッセージの外部URL：書ける／外部の連絡先：交換できる
- 売上が入る時期：毎月2日に前月分が確定し、2〜20日に申請すると当月末に入金（振込手数料270円）

出品前に確かめること

- [ ] note の規約・ヘルプの原文で、有料記事の購入者とメールで個別にやり取りすることが認められているかを確かめる（外部誘導の規定は見つからなかったが未確認）
- [ ] 売る形を決める：入口は有料記事（有料部分にメールアドレスと始め方を書く）、本番はメンバーシップの1対1プラン（公開できるプランは5つまで、月100〜50,000円）
- [ ] 特定商取引法上の販売業者に当たる場合は表示が必要（「請求があれば開示」で省略可、開示請求は note 運営経由）
- [ ] 手数料の計算の順（5%と10%）を料金ページの原文で確かめる

- メンバーシップの1対1プラン（2026-11-15、要約）：https://www.help-note.com/hc/ja/articles/900000164086
- 規約（景表法・薬機法・医療法に反する投稿の禁止）（2026-11-15、要約）：https://www.help-note.com/hc/ja/articles/360008947533

## MENTA

- やり取りの場所：MENTA のメッセージ
- ファイルの受け渡し：メッセージの添付は jpg・png・gif・pdf で8MBまで（古い記事。Excel は一覧にない）
- 出品文・メッセージの外部URL：書かない（禁止）／外部の連絡先：書かない（禁止）
- 売上が入る時期：支払いから30日たち、1,000円以上で出金できる（出金手数料300円）

出品前に確かめること

- [ ] メッセージに Excel（.xlsx）を添付できるかを確かめる（古い記事では jpg・png・gif・pdf だけ）。できなければ、MENTA の外の道具を使ってよいか（メンターが提案すれば可とある）を確かめ、使う場合は購入者の同意を取る
- [ ] 提供期間の上限が1か月（単発は30日）なので、本番（35日以上）は月額プランで2か月の契約にする
- [ ] メンティー側にも手数料10%がかかるため、買い手の支払いは価格の1.1倍になる
- [ ] ガイドラインの「医師法・薬事法に抵触するサービス」に当たらない書き方になっているかを確かめる

出典

- 手数料・出金（2026-11-15、要約）：https://intercom.help/mentajp/ja/articles/3025582
- 禁止事項（直接取引・医師法・薬事法）（2026-11-15、要約）：https://intercom.help/mentajp/ja/articles/4447150
- 添付ファイルの形式（2026-11-15、要約）：https://intercom.help/mentajp/ja/articles/3771287

## タイムチケット

- やり取りの場所：タイムチケットのメッセージ
- ファイルの受け渡し：メッセージの添付（1回5ファイル、pdf・xls・xlsx は20MBまで）
- 出品文・メッセージの外部URL：書かない（禁止）／外部の連絡先：書かない（禁止）
- 売上が入る時期：購入時の希望日時の24時間後に売上計上（振込手数料はホスト負担）

出品前に確かめること

- [ ] 手数料を確かめる（5万円以下25%と、一律10%の両方の記載がある）
- [ ] 数週間にわたる伴走を1つのチケットで売れるか（希望日時の24時間後に売上計上の仕組みとの合い方）を確かめる
- [ ] 出金時に本人確認書類が必要

- 外部リンクの禁止・連絡先の交換（2026-11-15、要約）：https://help.timeticket.jp/articles/19386

## 自分のサイト（Stripe）

- やり取りの場所：メール
- ファイルの受け渡し：メールの添付
- 出品文・メッセージの外部URL：書ける／外部の連絡先：交換できる
- 売上が入る時期：Stripe の入金（初回は7日後、その後は手動・週次・月次から選ぶ）

出品前に確かめること

- [ ] Stripe の禁止・制限業種（栄養補助食品は高リスク扱い）にこのサービスが当たらないかを確かめる。サプリを売るのではなく、記録の分析を売ることを説明できるようにする
- [ ] 特定商取引法に基づく表示を埋める（run site で【要記入】が残ると警告が出る）。住所・電話番号を「請求があれば遅滞なく開示」で省略する場合は、実際に開示できる体制にする
- [ ] 最終確認画面（支払いの直前）に、価格・支払いの時期・提供の時期・撤回の条件が出るようにする（特定商取引法12条の6）。Stripe の支払いページに出ない項目は、申し込みボタンの直前に書く（run site はボタンの上に出す）
- [ ] 記録の扱い（利用目的など）を公開してから受け付ける

- 通信販売の規制（2026-11-15、原文）：https://www.no-trouble.caa.go.jp/what/mailorder/
- Stripe の手数料（2026-11-15、要約）：https://stripe.com/en-jp/pricing
