# 1人実験の伴走サービス

> このディレクトリは、同じリポジトリのカウンセリングアプリとは**無関係の別事業**。
> 資産・顧客・収益を共有しない。別リポジトリに移すときは、このディレクトリごと移せば動く。

## 何をする事業か

お客さんが**自分で選んで飲んでいるサプリ**が、**その人の記録の上で**差を生んでいるかを、28日（月経周期を記録する人は56日）の実験で確かめる。成分ごとの体内での動き方（半減期など）を計算に入れ、睡眠日誌・装着型機器・生活記録を役割ごとに分けて分析する。

- **勧めない。** 成分や商品の提案はしない
- **効くとも言わない。** 言うのは「あなたの記録で出た差」だけ
- **ほぼ自動で回る。** 記録・リマインド・判定・レポート下書きは自動。担当者はコメントを添えるだけ

既存の習慣化の伴走は「続けさせる」サービス。これは「続けた結果、本当に差が出ているかを確かめる」サービス。この形の出品は、調査した範囲では見つからなかった。

## 目標

**2ヶ月で月5万円。** 本価格 ¥15,000 なら手数料22%を引いて月5件。達成できるかは調査では保証できず、出品して測る（[docs/01-service.md](docs/01-service.md)）。

## 順番

1. **自分が最初の被験者になる。** 今飲んでいるサプリで、まず7日間の普段通りの記録をつけ、`engine` の `plan` で自分に必要な日数を出す
2. 毎日の記録フォームを作り、エンジンとつなぐ（今は CSV で動く）
3. 出品前の確認を済ませる（[docs/04-compliance.md](docs/04-compliance.md) の未確認事項）
4. ココナラに出品する
5. 記録が溜まったら研究層を動かす

1の実験記録が、そのまま最初の事例とSNSの最初の投稿になる。
