# Andon Studio — 楽天アフィリ × Threads 運用

`/studio` は運用者専用の画面。楽天ランキングから商品を選び、悩み → Threads投稿 → 予約表 → 週次入れ替えまでを Claude で回す。
Andon（相談アプリ）と同じ「睡眠・集中・疲れ・不安・自己肯定感」の読者に向けた商品紹介アカウントを想定している。

## セットアップ（10分）

1. 楽天アフィリエイト と 楽天ROOM に登録する
2. `.env.local` を作る（`.env.example` 参照）
   - `ANTHROPIC_API_KEY` 必須
   - `STUDIO_PASSWORD` 本番では必須（未設定だと本番では Studio API が動かない）
   - `RAKUTEN_APP_ID` / `RAKUTEN_AFFILIATE_ID` 任意。入れるとランキングをAPIで取得でき、商品URLがアフィリエイトURLになる
3. `npm run dev` → http://localhost:3000/studio

## 流れ

| タブ | やること | Claude に任せる部分 |
|---|---|---|
| ① 商品 | ランキングを取得 or 貼り付け → 「10商品を選ぶ」→ ROOMに追加してチェック | 5,000円前後で悩みが一言で言える商品を10個選定 |
| ② 悩み | 「未生成の商品をまとめて」 → 使わない悩みのチェックを外す | 1商品あたり悩み30個 |
| ③ 投稿 | 読んで直して承認 | 悩み1つにつき投稿1本 |
| ④ 予約 | 開始日と時刻（初期値 1日3本）を決めて CSV をダウンロード → Threads の予約投稿へ | 商品が連続しないよう交互に並べる |
| ⑤ 週次 | 楽天アフィリの成果レポートを貼る → 入れ替えを反映 → ②に戻る | 売れた商品の共通点・外す商品・追加10個 |

毎日やるのは ③ の確認と ④ の予約（15分程度）。

## 生成ルール（`lib/affiliate/prompts.js`）

- 末尾に `#PR` を必ず入れる（ステマ規制）。`#PR` が無い投稿・500文字超の投稿は承認できない
- サプリ・寝具などで効能を断定しない（薬機法）
- 自分で使っていない商品で体験談を書かない。① で「自分で使ったことがある」にチェックした商品だけ一人称の体験表現を許可
- 商品リンクは本文に貼らず「プロフのROOM」に集約する

## 自動運転

手動の流れを自動化したものが `/studio/engine`。仕組みとセットアップは `docs/ENGINE.md`。

## 補足

- データはブラウザの localStorage に保存される（端末を変えると引き継がれない）
- モデルは `STUDIO_MODEL`（既定 `claude-opus-5-5`）。拒否時はサーバー側フォールバックを有効化している
- 楽天ランキングAPIの仕様変更でAPI取得が失敗する場合は、ランキングページの貼り付けで同じように動く
