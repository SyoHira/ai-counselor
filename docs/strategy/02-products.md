# 02. 商品の設計図

「何を、誰に、いくらで、どうやって作るか」まで書く。作れないものは商品ではない。

---

## ①即金：個別相談 ｜ ¥20,000 / 60分

| 項目 | 内容 |
|---|---|
| 誰に | 燃え尽き・不眠・虚無感を抱えた個人 |
| 何を | Andonアプリで事前に整理 → その内容を元に60分話す |
| 作るもの | 事前ヒアリングのフォームと、当日の進行台本（1日で作れる） |
| 月の上限 | **8本まで。超えたら断るか値上げする** |
| 本当の目的 | 現金ではなく、**「この言い方をしたら相手が黙った／泣いた」という生データ** |

**毎回必ず記録すること**（これをやらないと①が①のままで終わる）:
- 相手が使った言葉（本人の語彙をそのまま辞書に入れる）
- 刺さった言い換え
- 失敗した言い方

→ 週1回まとめて `lib/systemPrompt.js` の変換ルールに追記する。これが全商品の材料になる。

## ②スキル：AI相談ボットの構築代行 ｜ ¥400,000 / 件

| 項目 | 内容 |
|---|---|
| 誰に | カウンセリングルーム、コーチングスクール、産業医・EAP、ヘルスケアアプリ、フェムテック |
| 何を | その事業者専用の相談AIを作る。中身は Andon の辞書をその業界向けに調整したもの |
| 納品物 | システムプロンプト、禁止語リスト、危機対応フロー、テスト用の質問集、運用手順書 |
| 期間 | 2〜3週間 / 件 |
| 継続 | 月¥100,000 で保守（AIモデルが更新されるたびに出力を再確認する） |

**なぜ事業者が金を払うか**: この領域は言い方を間違えると即炎上・行政指導になるが、
社内に「言い方を設計できる人」がいない。だから外に出す。

**目標**: 継続3社で月¥300,000の固定収入。ここで生活費が固定できると、③の初速の遅さに耐えられる。

## ③-1 有料ニュースレター ｜ ¥1,480 / 月

| 項目 | 内容 |
|---|---|
| 誰に | 当事者本人＋対人支援者 |
| 何を | **週1回、言い方をひとつだけ配る** |
| 1回の中身 | ①よくある言い方 ②なぜそれが刺さるのか ③言い換え ④使う場面 の4ブロック、1,500字 |
| 作る時間 | 1回1時間（①の相談記録から自動的にネタが出る） |

**例**:
> ✕「やる気が出ない」
> ○「回復に予算が全部使われていて、他に回す分が残っていない状態」
> — やる気は性格ではなく残高の問題として説明すると、責める対象が消える。

**最優先で始める理由**: メールアドレスは、SNSの規約が変わっても、AIが進化しても消えない唯一の資産。
無料版を先に出し、8本たまってから有料に切り替える。

**目標**: 6ヶ月で有料200人（¥296,000/月）、12ヶ月で500人（¥740,000/月）

## ③-5 データベース販売『悩み × 言い方 × 対処』 ｜ ¥49,800（個人）/ ¥300,000（企業年間）

| 項目 | 内容 |
|---|---|
| 誰に | 支援者、ヘルスケア事業者、AI開発会社 |
| 何を | 「相談内容」→「使ってはいけない言葉」→「使う言葉」→「提案できる具体策」の対応表 |
| 形式 | YAML / JSON（そのままAIに読ませられる形） |
| 材料 | ①の相談記録＋②の案件記録が全部ここに流れ込む |
| 更新 | 四半期ごとに新版を配る → **買い切りでなく年額にできる** |

**これが③の中心。** ①②を続けるほど自動的に厚くなる唯一の商品。

## ③-6 ミニSaaS ｜ B2C ¥1,280/月 ・ B2B 従量

| | 内容 |
|---|---|
| **B2C** | Andonアプリ（現MVPの延長）。無料は月10回まで、超えたら課金 |

## ③-7 特化ブログ／ニッチメディア

- テーマ:「疲れの言語化」
- 書き方: 検索エンジンだけでなく、**AIに引用されることを前提に構造化して書く**（定義 → 例 → 言い換え の順）
- 変換表の一部を無料公開する。引用されるたびに Andon の言い方が広まる
- 役割: 全商品への入口

## 商品同士のつながり

```
①相談   ─┐
②代行   ─┴→ 記録が溜まる →  辞書が厚くなる
                              ↓
              ┌───────────────┼───────────────┐
        ニュースレター      テンプレ・講座      DB・SaaS
         （当事者）         （支援者）        （企業）
```

**1つの材料（辞書）から、3種類の相手に、7つの商品が出る。**
新しい商品を作るのではなく、同じものを違う形で包み直しているだけ。だから一人でも回る。
