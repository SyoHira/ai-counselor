## 結論（1ページ要約）

### 売り物の定義

売るのは「AIカウンセラー」ではない。

> **専門知を、人を責めない言葉に翻訳する技術。**

`lib/systemPrompt.js` に既に存在する「変換辞書」「禁止事項」「スタンス」こそが商品であり、
チャットUI（`app/chat`）はその辞書のショーケースにすぎない。
順序を逆にすると（アプリを主商品にすると）汎用LLMに数ヶ月で溶かされる。

### ポジション（空白地帯）

| プレイヤー | 身体（サプリ・睡眠・生理） | 言葉（責めない語り） |
|---|---|---|
| 汎用LLM（ChatGPT等） | 答えるが毎回ブレる | 設計なし・その場限り |
| メンタルヘルスアプリ（CBT系） | ほぼ踏み込まない | 体系的だが冷たい |
| バイオハック系発信者 | 非常に強い | 「意識高い＝自己責任」で燃え尽きた人を撃つ |
| カウンセラー・医療 | 扱えるが高コスト | 属人・スケールしない |
| **Andon** | **具体的に踏み込む** | **絶対に自己責任に落とさない** |

→ **「身体の話をしながら、本人のせいにしない」象限は空いている。**
バイオハックは自己責任と結びつきやすく、心理系は身体を避ける。両方をやると矛盾するから誰もやらない。
その矛盾を解いているのが Andon の変換辞書であり、これが唯一の独自性。

### 一文ポジショニング

> **燃え尽きた人が、自分を責めずに身体から回復するための、言葉と手順。**

### 3層の堀（時間が経つほど強くなる順）

| 層 | 内容 | 模倣コスト |
|---|---|---|
| L1 語彙資産 | 変換辞書・禁止語・トーン規約 | 中（見れば真似できる） |
| L2 応答パターン資産 | 実相談から抽出した「効いた返し」＋eval | 高（ログがないと作れない） |
| L3 関係性資産 | 継続ユーザー・声・コミュニティ | 極高（時間でしか買えない） |

L1だけでは守れない。**①②の受託で発生する「事故事例・失敗事例」をL1/L2に流し込む機構**が、
参照元の言う「①②の経験を③に変換する」の、この事業における具体形。
