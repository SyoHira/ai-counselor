# Andon 事業設計図

参照した副業フレーム:

```
①即金の副業   → 現金になる。でも残らない
②スキルの副業 → 実績になる。でも働き続けないと止まる
③本命の副業   → 初速は遅い。でも一度作れば何度も売れる

勝ち筋：①②で現金と実績を作り、その経験を③に変換する
（例）SNS運用代行 → テンプレ販売 → 講座 → 業界特化DB → ミニSaaS
```

これを Andon（AIウェルネス相談）に当てはめたのが本ドキュメント。

---

## 売るもの — 一言で

**「言い方」を売る。**

同じ内容でも、言い方で人は傷つくか、楽になるかが変わる。
Andon が持っているのは、その**言い方の辞書**（`lib/systemPrompt.js` に既に入っている）。

| ふつうのAIの言い方 | Andon の言い方 |
|---|---|
| 「愛着障害の可能性があります」 | 「幼い頃の経験が、今の人間関係のクセを作っている」 |
| 「報酬回路の炎症です」 | 「楽しいと感じる力が一時的に弱っている状態」 |
| 「前帯状皮質の自己監視が過剰です」 | 「疲れているときに大きくなる、自分を責める声」 |
| 「コルチゾール値の上昇です」 | 「身体にたまった疲労のサイン」 |

左は正しいが、読んだ人は「自分は壊れている」と感じる。
右は同じことを言っているのに、「仕組みの話」として受け取れる。

**この変換表が商品。** アプリはその見本市にすぎない。

---

## 変換の梯子（画像と同じ形）

```
AI相談ボットの構築代行        ← ②スキル。現金と、現場の生データが入る
        ↓
相談プロンプトのテンプレ販売   ← 代行で作った型を、そのまま商品に
        ↓
対人支援者向けオンライン講座   ← テンプレの使い方を教える
        ↓
「悩み × 言い方」DB販売       ← 案件と相談で溜まった変換表を売る
        ↓
ミニSaaS（Andon / 支援者向けツール）  ← DBをAPIとプロダクトにする
```

上に行くほど労働、下に行くほど積み上がる。
**上でやったことが、そのまま下の材料になる**のがこの梯子の要点。
代行で「この言い方は相手が黙った」と分かる → それがテンプレの1行になる → 講座の教材になる → DBの1レコードになる。

## 「一度作れば何度も売れる」の実額

| 商品 | 作る手間 | 1回あたり | 月10件なら |
|---|---|---|---|
| テンプレ | 最初に1回作るだけ | ¥19,800 | ¥198,000 |
| note | 最初に1回書くだけ | ¥2,980 | ¥29,800 |
| DB | 案件のたびに追記 | ¥49,800 | ¥498,000 |
| 講座（録画） | 最初に1回撮るだけ | ¥98,000 | ¥980,000 |
| ニュースレター | 週1回書く | ¥1,480/月 | 500人で¥740,000/月 |

代行は1件やって1件分の金しか入らない。上の表は**作った後、寝ていても売れる**。
この差を作るために①②をやる。
