# 06. 実装バックログ（事業からの逆算）

事業戦略（01-05）を、このリポジトリで何を書くかに落としたもの。
**優先順位は「コードとして面白いか」ではなく「売り物になるか／売れなくなるか」で決めている。**

---

## P0 — これが無いと ②③ を売れない

### P0-1. 危機対応プロトコル

- 対象: `lib/systemPrompt.js`（方針）＋ `app/api/chat/route.js`（検知と分岐）
- 内容: 希死念慮・自傷・虐待の検知 → 通常の相談フローから分岐 → 責めない言い方で公的窓口を案内
- 完了条件: eval ケース（危機表現サンプル）で分岐が100%発火。誤検知率の許容範囲を定義
- 事業上の意味: **05のP0。これ自体が Lexicon の最高値部分になる**

### P0-2. 変換辞書の切り出しとバージョニング

- 対象: `lib/systemPrompt.js` → `lib/lexicon/`
- 構成案:
  ```
  lib/lexicon/
    version.js        # v0.1.0
    translations.js   # 専門語 → 責めない言い換え（現9項目 → 100項目へ）
    forbidden.js      # 禁止語（脳部位・神経伝達物質・学派名・診断語・効能語）
    stance.js         # スタンス定義
    crisis.js         # 危機対応フロー
    build.js          # 上記からシステムプロンプトを生成
  ```
- 完了条件: `systemPrompt` が辞書から生成される形になり、辞書だけを単体で配布できる
- 事業上の意味: **辞書を商品として切り出せない限り、02-③c は永久に売れない。ここが商品化の物理的前提**

### P0-3. 薬機法対応（サプリ記述の書き換え）

- 対象: `lib/systemPrompt.js` のサプリメント知識セクション
- 内容: 効能見出しの削除、用量断定の回避、禁止語への「診断・治療・予防」の追加
- 完了条件: チェックリスト（`docs/strategy/05` 由来）全項目クリア

## P1 — 資産が積み上がる仕組み

### P1-1. eval ハーネス

- 内容: 入力サンプル → 出力を検査（禁止語が出ていないか／言い換えが守られているか／危機分岐が動くか）
- 完了条件: `npm run eval` で回帰テストが通る
- 事業上の意味: **L2資産の器。これがないと「モデル更新に追随する保証」を売れない（②の継続保守の根拠）**

### P1-2. 会話ログの匿名収集（同意ベース）

- 完了条件: オプトイン UI ＋ 匿名化 ＋ 保存方針の明記（05-P2 準拠）
- 事業上の意味: L2の原材料。ただし**同意設計を先にやらないと資産が負債になる**

### P1-3. モデル更新

- 現状 `app/api/chat/route.js` は `claude-sonnet-4-20250514` を指定。現行世代（Sonnet 5 系）へ更新し、
  更新の前後で P1-1 の eval を回して**出力品質が辞書通りに保たれるか**を確認する
- 事業上の意味: このプロセス自体が②の商品（モデル追随保守）の実演になる

## P2 — 収益導線

### P2-1. メール登録導線

- 対象: `app/page.jsx`（`CommunityInsights` の下、免責の上）
- 内容: ニュースレター登録フォーム
- 事業上の意味: **02-③a。唯一奪われない資産の入り口。実装コストに対して回収が最も大きい**

### P2-2. 課金導線（B2C サブスク）

- 内容: 無料枠（月N回）→ 有料（¥1,280/月）
- 優先度は P2-1 より低い。**リストが先、課金が後**

### P2-3. Guardrail API（B2B）

- 内容: テキストを受け取り、禁止語検出・言い換え・危機検知の結果を返すエンドポイント
- 前提: P0-2 と P1-1 の完了
- 事業上の意味: **02-③d の本命。B2Cアプリより収益性が高い**

## 実装順序

```
P0-1 危機対応 ─┐
P0-3 薬機法   ─┼→ P0-2 辞書切り出し → P1-1 eval → P2-3 Guardrail API
P2-1 メール導線┘                    └→ P1-2 ログ収集 → L2資産
```

P2-1（メール導線）だけは P0 と並行してよい。実装が軽く、**1日でも早く始めた分だけリストが積み上がる**ため。
それ以外は上の順序を崩さない。特に **P0-2（辞書切り出し）より先に P2-2（課金）をやらない。**
売れないものに課金を付けても意味がなく、辞書が切り出せていなければ売り物は存在していない。
