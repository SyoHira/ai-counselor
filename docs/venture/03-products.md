# 03. 商品 — 4つの型の割り当て

4つの型を別々の事業としてやるのではなく、**1本のパイプラインから4つを切り出す。**
だから作業は増えない。

| 型 | 何になるか | 役割 |
|---|---|---|
| 単機能ツール量産 | 無料ツール群 | 集客の面を取る |
| 相場データ | 成分ごとの公開ページ・週報 | 引用され、リストが溜まる |
| 変更履歴 | 有料アラート・監視 | **月額収入の本体** |
| 失敗事例DB | 表現の失敗事例集 | 高単価。参入障壁 |

---

## 型①：単機能ツール量産（無料・集客）

作るのは小さいものを数十個。パイプラインの出力を1画面に切り出すだけなので、1個あたり数時間。

| ツール | 中身 |
|---|---|
| 成分の今週 | 成分名を入れると、行政・AI・市場の最新状態と直近の変化が出る |
| AI回答くらべ | 1つの質問に対する各AIの答えを並べる |
| 届出ステータス確認 | その成分の届出状況と、撤回の履歴 |
| 表現チェッカー | 商品説明文を貼ると、過去に措置命令が出た表現に近いものを指摘（**判定はしない。似た事例を示すだけ**） |
| 配合量くらべ | 同じ成分の主要商品の配合量を並べる |
| 成分カレンダー | この1年で扱いが変わった成分の一覧 |

**目的は収益ではなく入口。** 「成分名 + 何か」で検索した人と、AIに聞いて引用された経路の両方を拾う。
無料ツールは全ページから週報への登録に繋ぐ。

---

## 型②：相場データ（無料公開＋有料の深堀り）

### 無料：成分ページ

成分ごとに1ページ。今の価格帯、配合量の分布、AIの説明、届出状況。
**引用されることが目的**なので、出典と観測日を必ず明記し、数字は誰でも検証できる形で出す。

### 無料：週報（メール）

毎週1回。「今週変わったもの」だけ。**リストがこの事業の唯一の逃げ場**（検索もAIも経路が消える可能性があるが、メールアドレスは消えない）。

### 有料：業界レポート（四半期）｜ ¥150,000

四半期の全変化をまとめ、成分カテゴリごとの動きを整理したもの。
中身はパイプラインの出力の切り出しなので、**作る手間はほぼ編集作業だけ。**

---

## 型③：変更履歴の監視（有料・月額）← 本体

**この事業の収益の中心。**

| プラン | 対象 | 月額 |
|---|---|---|
| 単成分 | 成分1つを全軸で監視 | ¥30,000 |
| ブランド | 自社の主力成分5〜10個＋自社ブランド名の言及 | ¥80,000 |
| 業界 | カテゴリ全体（例：睡眠系成分すべて） | ¥150,000 |

提供するもの:
- 変化があったときの即時通知（届出撤回、AIの評価反転、競合の配合変更）
- 月次の推移レポート
- 過去に遡った時系列の閲覧

**なぜ月額が続くか**: 一度知ってしまうと、知らない状態に戻れないから。
「AIが自社製品を何と言っているか」を把握した企業は、翌月も見たくなる。解約は変化が止まったときだけで、変化は止まらない。

**20社 × 平均¥50,000 = 月¥1,000,000。** 一人で運用できる上限はまだ先にある。

---

## 型④：失敗事例DB（高単価）

措置命令・課徴金の公表事例、届出撤回の事例、AIが出した危険な回答。これを成分別・表現別に整理したもの。

| 商品 | 価格 |
|---|---|
| 表現の失敗事例集（年間ライセンス） | ¥300,000/年 |
| 緊急調査（「AIが自社をこう言っている、いつからか」を遡って調べる） | ¥200,000/件 |

**なぜ高いか**: 表現ひとつで措置命令を受ける業界で、過去の事例が体系化されていない。
各社が自社の失敗しか知らない状態にある。**横断して持っているのは観測している側だけ。**

**注意**: 事実の記録に徹し、論評しない。「この表現はアウト」ではなく「この表現に対して過去にこういう処分の公表があった」と書く。判断は顧客と顧客の弁護士がする。

---

## 収益の積み上がり方

| 商品 | 作る手間 | 収入の性質 |
|---|---|---|
| 無料ツール | 1個あたり数時間・1回きり | 収入ゼロ。入口 |
| 成分ページ | 自動生成 | 収入ゼロ。引用される |
| 週報 | 自動出力＋30分の編集 | 収入ゼロ。リストになる |
| **監視（月額）** | **パイプラインが回っていれば追加ゼロ** | **顧客が増えるほど積み上がる** |
| 四半期レポート | 編集のみ | 3ヶ月に1回まとまって入る |
| 失敗事例DB | 週次の記録が勝手に溜まる | 年額 |
| 緊急調査 | 都度作業 | スポット |

**監視の顧客が1社増えても、作業は増えない。** ここが記事販売やコンサルとの決定的な違いで、
一人のまま収入だけが伸びる唯一の構造になっている。
