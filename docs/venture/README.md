# AI検索での見え方を、健康食品事業者に売る

> 同リポジトリのカウンセリングアプリとは無関係の別事業。立ち上げが決まった時点で別リポジトリに切り出す。

## 前提条件（これが設計を決めている）

| 条件 | 内容 |
|---|---|
| 収入 | **初月から入金があり、徐々に大きくなる構造が必要** |
| 読者・リスト | **ほぼゼロ** |
| 使える技術 | Next.js + LLM API で計測パイプラインを自作できる |
| 持っている知識 | 成分・健康分野と、AI/開発ツールの両方 |

**読者ゼロで初月に入金がある方法は実質1つ。** 既に予算が付いていて探している人のところへ、自分から持っていく。
ニュースレター・教材・メディアは、読者ゼロなら初月ゼロ円になる。だから**最初はやらない**。

## 何を売るのか

**健康食品・サプリ事業者に対して、AI検索での自社の見え方を測って渡す。**

1. 初回：診断レポート（単発）
2. 継続：月次モニタリング
3. 蓄積後：業界横断のベンチマーク、レポート販売、ツール化

売るのは意見ではなく**測定結果**。「こうすべき」ではなく「今こう言われている」。

---

## 差別化できる可能性がある3点

汎用LLMO会社20社に対して勝てるとしたら、ここだけ。

1. **健康食品は薬機法があり、AIの発言リスクの質が他業界と違う**
   AIが「効果がある」と言い、企業がそれを引用したら問題になる。逆にAIが「根拠は限定的」と言い始めたら売上が落ちる。
   SEO会社はこの判断ができない
2. **成分の知識と規制の知識を両方持つ人間が質問を設計する**
   何を聞くかが変われば、出てくる結果も変わる
3. **計測パイプラインを自作している**
   20社の多くは海外ツールの再販＋コンサル。自前で持てば原価と柔軟性が違う

**この3点が本当に効くかは未検証。** 20社に当たった反応で判定する（01参照）。
健康食品特化のLLMOサービスは検索では見つからなかったが、「無い」ことの確証ではない。
