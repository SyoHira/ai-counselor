# 成分観測所（仮）— 事業設計

> **このディレクトリは、同リポジトリのカウンセリングアプリ（Andon）とは無関係の別事業。**
> 資産も顧客も収益も共有しない。立ち上げが決まった時点で別リポジトリに切り出す。

---

## アイデア

**成分をめぐる情報の変化を、行政・AI・市場の3面から毎週記録し続ける。**

サプリや健康食品の成分は、扱いが静かに変わり続けている。

| 変わるもの | どこで変わるか | 変わると何が起きるか |
|---|---|---|
| 制度上の扱い | 機能性表示食品の届出・撤回、健康被害の報告、指定成分の追加 | 商品が売れなくなる。表示の作り直し |
| AIの説明 | ChatGPT・Claude・Gemini等がモデル更新のたびに言うことを変える | 消費者が最初に見る情報が変わる。売上に直結 |
| 市場の実勢 | 価格、配合量、新製品、撤退 | 競争条件が変わる |

3つとも**変化が速く、時系列で持っている人が誰もいない。**
今日の状態はどこでも調べられる。「先月と何が変わったか」はどこにも無い。

**だから、記録し続けること自体が商品になる。**

---

## なぜこの2つの交差点なのか

この事業は、片方の知識だけでは成立しない。

- **AI・開発ツール側**がないと、毎週数百件を自動で取得・比較するパイプラインが作れない。
  各AIのAPI仕様も料金も更新頻度も変わるので、追随の勘所が要る
- **健康・サプリ側**がないと、何を質問すべきか設計できず、返ってきた答えの妥当性も判断できない。
  制度（機能性表示食品、景品表示法、薬機法）の意味が読めないと、変化に気づけない

両方持っている人は少ない。ここが参入の狭さになる。

---

## 何が資産になるか

**時間**。これだけ。

2026年10月に観測を始めれば、2027年10月には**1年分の時系列を持っている唯一の存在**になる。
後から参入した人は、過去に遡ってデータを取ることが原理的にできない。

これは記事やテンプレのような「作り置き」より強い。
作り置きは作った時点で価値が固定されるが、**観測データは自分が寝ている間に増える。**

---

## 流れ（事業の回り方）

```
              毎週の自動観測
    行政の公開データ ／ 各AIの回答 ／ 市場価格
                    │
              前週との差分を抽出
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
    無料ツール群   無料の週報    有料アラート
    （検索で拾う） （リスト化）  （月額・本命）
        └───────────┴───────────┘
                    │
              観測ログが溜まる
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
    データ販売    業界レポート   スポット調査
     ／API      （四半期）    （緊急案件）
```

**1本のパイプラインから、無料の集客も月額収入もデータ販売も全部出る。**
商品を増やしているのではなく、同じ観測結果を違う粒度で切り出しているだけ。だから一人で回る。

## 誰が金を払うか

| 相手 | 払う理由 |
|---|---|
| サプリ・健康食品メーカー | 自社の主力成分が、AIに「効果は限定的」と言われ始めたら売上が落ちる。届出撤回や健康被害の報告は事業リスクに直結する。**どちらも今は誰も見ていない** |
| D2C・通販 | 商品ページの表現リスク、競合の値動きと配合の変化 |
| 薬事コンサル・広告代理店 | クライアントへの説明材料。自分で集めると人件費が合わない |
| 商社・原料メーカー | どの成分が伸びて、どれが沈むか |
| メディア・アフィリエイター | ネタ元。無料層で捕まえて有料に上げる |
