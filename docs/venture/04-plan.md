# 04. 実行計画

**最優先はパイプラインを回し始めること。** 商品も営業も後でいい。
観測していない期間は、後から絶対に取り戻せない。1日遅れれば1日分のデータが永久に欠ける。

---

## 90日

### 第1〜2週：観測を始める（商品はまだ作らない）

| やること | 完了の判定 |
|---|---|
| 成分リスト100種を確定（市場規模と話題性で選ぶ） | 一覧が確定 |
| 質問セット500問を設計 | 5型 × 100成分 |
| データソースの利用条件を一次情報で確認（05） | 使えるものが確定 |
| 取得→保存→差分のパイプラインを実装 | 手動実行で1周する |
| **初回スナップショットを取得** | **観測開始日が確定する** |

**この2週間が事業の全て。** ここが遅れた分だけ、資産の開始が遅れる。

### 第3〜6週：無料の面を作る

| やること | 目標 |
|---|---|
| 週次の自動実行に切り替え | 手を触れずに毎週溜まる |
| 成分ページを自動生成して公開 | 100ページ |
| 無料ツールを3本公開 | 成分の今週／AI回答くらべ／配合量くらべ |
| **無料週報を開始** | 4号配信・登録100件 |

### 第7〜12週：最初の金を取る

| やること | 目標 |
|---|---|
| メーカー・代理店へのヒアリング20社（売り込みでなく「見せて反応を見る」） | 20件 |
| 監視プランの提供開始 | **有料3社（¥150,000/月）** |
| 緊急調査を1件受ける | ¥200,000 |
| 無料ツールを10本まで増やす | 検索の面を広げる |

**90日終了時**：観測13週分／有料3社／週報登録300件／月商 ¥150,000-350,000

---

## 12ヶ月

| 時期 | 主眼 | 到達 |
|---|---|---|
| 1-3ヶ月 | 観測を止めずに回す。無料の面を作る | 有料3社・月商¥150,000-350,000 |
| 4-6ヶ月 | 監視を売る。事例を作る | 有料8社・月商¥400,000-600,000 |
| 7-9ヶ月 | 失敗事例DBと四半期レポートを出す | 有料15社・月商¥800,000-1,100,000 |
| 10-12ヶ月 | データ販売・API。成分を200種に拡張 | 有料20社超・月商¥1,200,000-1,600,000 |

### 2年目以降

観測2年分の時系列は、この時点で他の誰も持っていない。
ここから先の商品は、作るのではなく**溜まったものを切り出すだけ**になる。

- 年次の業界データブック
- 過去データへのAPIアクセス（研究・投資・商社向け）
- 海外市場への横展開（同じパイプラインの対象を変えるだけ）

月商 ¥3,000,000 の内訳は、監視30社＋データ販売＋レポート。**作業量は1年目とほぼ同じ。**

---

## 見る数字はこれだけ

| 指標 | なぜこれか |
|---|---|
| **観測を欠かした週の数** | **0を維持する。1週欠けると、その週の変化は永久に取れない** |
| 有料顧客数 | 月額の本体 |
| 解約率 | 月5%を超えたら、通知の中身が薄い |
| 週報の登録数 | 唯一奪われない経路 |

売上ではなく、**まず観測の連続性**を見る。売上は後からついてくるが、欠けたデータは戻らない。

---

## やめる・変える基準

| こうなったら | 時期 | どうするか |
|---|---|---|
| ヒアリング20社で「金を払う」が0件 | 4ヶ月 | 相手をメーカーから代理店・薬事コンサルに変える（自分で集める人件費が合わない層） |
| 有料が3社から増えない | 9ヶ月 | 監視の単品売りをやめ、業界レポートとデータ販売に寄せる |
| AI側のAPIが使えなくなった | 随時 | 行政＋市場の2軸に縮小して継続。**観測を止めることだけはしない** |
| 大手が同じことを始めた | 随時 | 過去データは追いつかれない。より狭く深い成分カテゴリに絞る |

いずれも観測は止めない。止めた瞬間、この事業の資産が増えなくなる。
