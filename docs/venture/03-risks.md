# 03. リスクと、外れたときの手

---

## 検証していない仮説（最大のリスク）

**健康食品事業者が、AI検索での見え方に金を払うかどうかは、まだ確認していない。**

分かっていること：LLMO対策の市場は存在し、月10〜100万円が動いている（[出典](https://prtimes.jp/main/html/rd/p/000000201.000149156.html)）。
分かっていないこと：**その金を払っているのが健康食品業界かどうか。**

健康食品特化のサービスは検索では見つからなかったが、これは「無い」の証拠にはならない。
- 本当に空いている（好機）
- 需要が無いから誰もやらない（罠）

**どちらかは01の7日間で分かる。** それまでこの事業に時間もお金も追加投入しない。

---

## 仮説が外れたときの手

| 外れ方 | 分かる時期 | 次の手 |
|---|---|---|
| 20社送って返信ゼロ | 1週間 | 相手を変える：薬事コンサル、広告代理店、原料メーカー。**同じレポートがそのまま使える** |
| それでもゼロ | 2週間 | 業界を変える：医療・クリニック、化粧品、法律・士業。いずれも「AIの言い方」がリスクになる業界。手順は同一 |
| 反応はあるが金にならない | 1ヶ月 | 診断を無料にして、月次モニタリングだけ有料にする（単発で満足されるのを防ぐ） |
| 大手SEO会社が健康特化を始めた | 随時 | 測定の深さで差をつける。競合はコンサルが本体で、計測は外注ツール |

**業界を変えても、パイプラインとレポートのテンプレはそのまま流用できる。**
だから最初の1週間の投資は、外れても無駄にならない。

## 規約・法務

| 論点 | 方針 |
|---|---|
| AIの回答取得 | **公式APIのみ。** 画面の自動操作や規約外の自動アクセスはしない。事業の根幹が規約違反の上に載ると、いつ止まってもおかしくないうえ、コンプライアンスが重い業界の顧客に説明できない |
| 競合他社を測って結果を渡す | 公開されているAIの回答を記録するだけで、意見を含まない。**論評しない**。「A社は4/5、御社は1/5」という事実のみ |
| 自分の発信内容 | 「効く／効かない」を自分の判断として書かない。「AIはこう答えた」と書く。**判断を売らないことが、法的な安全と中立の信用を同時に作る** |
| 薬機法・景表法 | 自分は商品を売らないので広告規制の直接の対象になりにくいが、書き方次第で踏む。業務として本格化する前に、薬事に詳しい専門家に一度見せる |
| 行政の公開データを使う場合 | 提供形式・再配布の可否・出典表記の要件を、使う前に一次情報で確認する（[消費者庁 機能性表示食品の届出](https://www.caa.go.jp/policies/policy/food_labeling/foods_with_function_claims/notice/)） |

## 実務上の落とし穴

- **AIの回答の揺らぎを「変化」と誤読する** → 必ず3回投げる。1回だけの違いはノイズ
- **顧客ごとに手作りレポートを書く** → 10社で破綻。テンプレ化を1社目でやる
- **競合を測るのを省略する** → データが溜まらない。02の設計が丸ごと死ぬ
- **生ログを捨てる** → 「◯月時点ではこうだった」が言えなくなる。全文残す
