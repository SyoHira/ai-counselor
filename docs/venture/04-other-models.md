# 04. 他の事業モデル

## 全部、同じエンジンで動く

`ai-visibility/` に作ったものは、突き詰めるとこれ以上のことをしていない。

> **同じ入力を、複数のモデルに、複数回投げて、差分と傾向をレポートにする。**

対象を差し替えるだけで別の事業になる。だから**入口を複数試して、当たったところに集中する**という進め方ができる。
エンジンを作り直す必要がないので、2つ目以降の事業は1〜2週間で試せる。

```
                    ┌─ A 健康食品のAI可視性   ← いま動かすもの
                    ├─ B 表現リスクの照合
  共通エンジン ─────┼─ C 届出まわりの文献レビュー
  （投げる／照合    ├─ D LLMプロダクトの出力回帰テスト
    する／差分を    ├─ E 医療・クリニックへの横展開
    レポートに）    └─ F 成分・原料の市場データ
```

**重要な順序**：エンジンは変えない。入口だけ変える。
Aで20社に送って0件なら、Bで20社に送る。Bで0件ならC。これを回す。

---

## B. 表現リスクの照合

| | |
|---|---|
| **誰に** | 健康食品D2C、広告代理店、ECモール出店者、アフィリエイト事業者 |
| **何を** | 商品LP・広告文を入れると、過去に処分が公表された表現に**近いもの**を提示する |
| **価格** | 単発レビュー ¥30,000〜/1LP、継続 ¥50,000〜/月 |

**初月に金が入る理由**：この業界には**すでに薬事チェックに金を払う習慣がある**。
新しく需要を作る必要がなく、既存の支払いを速く安くするだけ。

**積み上がるもの**：照合した文言と結果。溜まるほど「この言い回しは過去にこうなった」の精度が上がる。
最終的に事例DBそのものが商品になる。

**差別化**：既存の薬事チェックは人手で、高くて遅い。ツール化されているものは少ない。

**最初の1週間**：公表されている処分事例を集めて構造化 → 実在のLP20本を照合 → 1社分のレポートを作って送る。**Aと手順が同一。**

**譲れない設計**：**「違法です」と書かない。**
「この表現に近い公表事例があります」に徹する。判定を断定した瞬間に責任を負い、中立の立場も失う。

## C. 届出まわりの文献レビュー（下請け）

| | |
|---|---|
| **誰に** | 薬事コンサル事務所、健康食品メーカー |
| **何を** | 機能性表示食品の届出に要る文献の検索・要約・エビデンス整理 |
| **価格** | 1件 ¥100,000〜 |

**初月に金が入る理由**：ここが一番速い可能性がある。
**薬事事務所はすでに存在し、すでに受注している。** 顧客開拓が1段階省ける。
新規開拓ではなく、既に仕事を持っている人の手が足りない部分を取りに行く形。

**積み上がるもの**：成分 × 論文 × 届出表現の対応DB。
Aの計測結果（AIが成分をどう説明しているか）と**同じ成分軸で結合できる**ので、AとCは相互に強くなる。

**差別化**：薬事事務所の本業は法務で、文献レビューは手作業か外注。ここは速度差が大きく出る。

**弱点**：**品質責任が重い。** 誤りが届出の差し戻しに直結する。
最初は必ず人が全件確認する前提で受ける。速度だけで安請け合いすると一度で終わる。

## D. LLMプロダクトの出力回帰テスト

| | |
|---|---|
| **誰に** | LLMを本番に載せている日本企業 |
| **何を** | モデル更新やプロンプト変更で出力が壊れていないかを検査する仕組み |
| **価格** | 導入支援 ¥300,000〜、運用 ¥100,000〜/月 |

**エンジンとの関係**：**Aと完全に同一。** 同じ入力を複数回投げて差分を見る、そのもの。
Aで作ったコードがほぼそのまま使える。

**初月に金が入る理由**：導入支援を受託として売れる。

**積み上がるもの**：評価データセットと、業種別の失敗パターン。

**差別化**：既存の評価基盤は海外・英語圏中心。
日本語での評価と、日本の業種固有の禁止表現（薬機法、金融、医療）に寄せる余地はある。

**弱点**：競合が強く、相手が技術者なので価格が上がりにくい。
**AやBが当たらなかったときの次の手**という位置づけが妥当。

---

## E. 医療・クリニックへの横展開

Aのパイプラインで、対象を病院・クリニック・治療院に差し替えるだけ。
医療広告ガイドラインがあるため、**AIの発言リスクという構造が健康食品とまったく同じ。**

- 追加の開発はほぼゼロ
- 営業手順も同一
- ただし広告規制は健康食品よりさらに厳しい。判断を売らない原則をより厳密に守る

**Aで健康食品が刺さらなかった場合の、最も安い次の候補。**

---

## F. 成分・原料の市場データ

| | |
|---|---|
| **誰に** | 原料商社、OEM、投資家 |
| **何を** | どの成分が伸びているか（新製品の投入数、AIでの言及数、届出数の推移） |

**これは初月の商品にならない。** 時系列が数ヶ月ぶん溜まって初めて売れる。
Aを続けていれば副産物として自動的に出てくるので、**狙って作るのではなく、出てきたら売る。**

---

## 試す順序

| 順 | 事業 | 試す理由 | 見切り |
|---:|---|---|---|
| 1 | **A** 健康食品のAI可視性 | エンジンが動いている。相場が高い（月10〜100万円） | 20社送って0件 |
| 2 | **C** 届出の文献レビュー | 顧客がすでに受注している。開拓が1段階少ない | 薬事事務所10社で0件 |
| 3 | **B** 表現リスク照合 | 支払い習慣がある。Aと同じ顧客に売れる | 20社で0件 |
| 4 | **E** 医療への横展開 | 追加開発ゼロ | 20社で0件 |
| 5 | **D** 出力回帰テスト | 競合が強いので後 | — |

**A・B・C は顧客が重なる。** 1社と関係ができれば、残り2つを同じ相手に出せる。
だから最初の1社を取ることの価値が、売上の額面より大きい。

---

## この構成が壊れる条件

- **エンジンを事業ごとに作り直す** → 2つ目以降が1〜2週間で試せなくなり、この設計の利点が消える
- **同時に複数を営業する** → 全部が中途半端になる。1つずつ、見切りをつけて次へ
- **当たる前に作り込む** → Aがまだ1社も取れていない段階でBのツールを磨くのは、逃避でしかない
